# Icon sources

Devicon icons are from revision [`7330accdbc47e2dc0c19789a48533c4a3c50fe58`](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58), under the accompanying `LICENSE` (MIT).

OpenAI, Claude, Anthropic, ElevenLabs, and MCP icons are from [`@lobehub/icons-static-svg` version 1.95.0](https://www.npmjs.com/package/@lobehub/icons-static-svg/v/1.95.0). The accompanying `LICENSE-LOBE` was retained from the matching `@lobehub/icons` 1.95.0 package (MIT).

The SVGs have been placed in locally designed, labeled tiles with a pale background for contrast in light and dark GitHub themes. Monochrome AI icons receive explicit colors. React Native reuses the React mark; Spring Boot uses the Spring mark; Redux / RTK Query share the Redux mark. The generic SQL database glyph is original artwork for this profile.

Brand names and logos belong to their respective owners. They identify technologies used and do not imply endorsement.
